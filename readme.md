# 公考笔记

> 考公 · 考研 · 笔记 · 课程｜一页直达的备考资料索引
> 网址：**gkbj.net**

## 这是什么

「公考笔记」是一个面向考公、考研人群的**资料索引站**。备考资料往往散落在收藏夹、聊天记录和网盘群里，找一次要翻半天；这个网站把课程目录、免费笔记和更新日志收进同一页，点开卡片即可直达对应的腾讯文档。

它本身**不托管课程文件**，也不要求注册登录，只做一件事：把「去哪儿找资料」这件事变简单。资料内容以对应的腾讯文档和公众号为准，站点长期维护链接与更新日志。

## 设计与体验

- 视觉走「手账笔记本 × 新粗野主义」：米白点阵纸、活页装订孔、荧光笔高亮、彩色胶带贴纸、粗描边配彩色硬阴影的卡片，整体明亮清新。
- 两张公众号二维码以原图比例内嵌在页面里，不裁切、不变形，页面无需加载任何外部图片。
- 交互轻量：卡片悬停反馈、QQ 一键复制、悬浮返回顶部、窄屏自动重排。
- 零外部依赖（无 CDN、无外部字体、无第三方脚本），加载快，也方便整体搬迁。
